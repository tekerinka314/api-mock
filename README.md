# API-мок для фронтенду

Локальний HTTP-сервер з редактором маршрутів і демокаталогом. Для запуску потрібен Node.js 24 або новіший із npm. Сторонніх залежностей немає.

```sh
npm start
npm test
```

Після `npm start` відкрийте [редактор](http://127.0.0.1:4311/) або [демокаталог](http://127.0.0.1:4311/demo).

1. У редакторі виберіть варіант маршруту `GET /mock/products`. Для іншого стану позначте «Зробити цей варіант активним» і натисніть «Зберегти зміни».
2. Натисніть «Оновити каталог». Початкова конфігурація відтворює список товарів, порожній список, помилку HTTP 500 та завантаження з паузою 1000 мс.
3. Перегляньте в журналі метод, шлях, HTTP-статус і тривалість запиту.
4. Щоб налаштувати власну відповідь, змініть поля вибраного варіанта або додайте маршрут чи варіант, заповніть поля та збережіть. Сервер зіставляє метод GET або POST і точний шлях у `/mock/…`. Параметри запиту на вибір маршруту не впливають.

Початкова конфігурація зберігається в `config/default.json`. Зміни записуються у `var/config.json`. Щоб відновити початкові дані, зупиніть сервер, видаліть `var/config.json` і запустіть сервер знову.
